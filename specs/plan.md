- Set up Docusaurus
- Create sidebar and docs structure
- Write all chapters based on specification

## Phase 2 — RAG Preparation
- Extract markdown content
- Generate embeddings
- Store embeddings in Qdrant

## Phase 3 — Backend Development
- Build FastAPI endpoint for:

  - /query
  - /chat
- Connect to Qdrant

## Phase 4 — Frontend Chatbot
- Create UI widget inside Docusaurus
- Connect to backend

## Phase 5 — Deployment
- Deploy Docusaurus on GitHub Pages
- Deploy backend to Render or Vercel
- Test complete RAG pipeline

## Phase 6 — Final Review
- Fix formatting issues
- Add missing examples
- Run user testing
