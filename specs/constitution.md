# Project Constitution

## Purpose
Create a structured technical book using Docusaurus and build a RAG-based chatbot that can answer questions from the book.

## Writing Style Rules
- Tone: Clear, beginner-friendly, and practical.
- Sentences must be short and simple.
- Use examples whenever a concept is explained.
- Avoid unnecessary jargon.
- Use headings, bullet points, code blocks, and diagrams.
- Maintain consistent formatting across every chapter.

## Chapter Structure Rules
Each chapter must follow:
1. Introduction  
2. Concepts explained  
3. Examples  
4. Best practices  
5. Summary  

## Formatting Rules
- Use Markdown only.
- Use code blocks with correct syntax highlighting.
- Do not include overly advanced examples unless required.

## Chatbot Guiding Rules
- Chatbot should answer ONLY from book content.
- If no answer exists, the chatbot must say “Not found in the book.”
- RAG must always prioritize exact matched content.

## Prohibited
- No hallucination.
- No making up concepts not defined in the book.
